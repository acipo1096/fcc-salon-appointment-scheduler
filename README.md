# Salon Appointment Scheduler

## Description
This project, part of freeCodeCamp's "Relational Database" certification, asks students to create an interactive Bash program that uses PostgreSQL to track the customers and appointments for a salon.

The *salon.sql* file is a dump of the commands used to create the database according to the user stories and specifications. The *salon.sh* is a Bash script that shows how data is entered into the database and queried for desired results.
